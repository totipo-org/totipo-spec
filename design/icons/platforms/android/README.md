# Android icons

Contents:
- `res/mipmap-anydpi-v26/ic_launcher.xml`
- `res/mipmap-anydpi-v26/ic_launcher_round.xml`
- adaptive icon layers in `res/drawable/`
- legacy launcher PNGs in density-specific `mipmap-*` folders
- `play-store-512.png`

Notes:
- Adaptive icon uses a full-bleed green gradient background and a white foreground symbol.
- Legacy launcher icons use the full precomposed icon.
